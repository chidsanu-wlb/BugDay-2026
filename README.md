# SCK Insurance - Mock Data Generator
## คู่มือการใช้งานสำหรับ QA Manual

---

## วัตถุประสงค์ของโปรเจ็ค

โปรเจ็คนี้เป็นการทดลองเขียน Prompt เพื่อให้ AI สร้าง Python Script สำหรับสร้างข้อมูลจำลอง (Mock Data) สำหรับการทดสอบระบบประกันครอบครัว (Family Bundle Insurance Renewal Campaign)

**เป้าหมาย:**
- ฝึกฝนการเขียน Prompt ให้ AI เพื่อสร้าง Python Script ที่สามารถสร้าง Test Data ที่มีความสมจริงใกล้เคียง Production ได้
- ใช้ AI ช่วยสร้างข้อมูลทดสอบที่ซับซ้อนตามเงื่อนไขทางธุรกิจ
- ลดเวลาในการสร้าง Test Data แบบ Manual

## ขั้นตอนการเริ่มต้น 

### 1. ติดตั้ง Python

**สำหรับ Windows:**
1. เข้าเว็บไซต์ https://www.python.org/downloads/
2. ดาวน์โหลด Python เวอร์ชันล่าสุด
3. รันไฟล์ติดตั้ง
4. **สำคัญ:** ติ๊กเลือก "Add Python to PATH" ก่อนกด Install
5. หลังติดตั้งเสร็จ เปิด Command Prompt แล้วพิมพ์:
   ```
   python --version
   ```
   ถ้าขึ้นเวอร์ชันแสดงว่าติดตั้งสำเร็จ

**สำหรับ Mac:**

**วิธีที่ 1: ดาวน์โหลดไฟล์ติดตั้ง**
1. เข้าเว็บไซต์ https://www.python.org/downloads/
2. ดาวน์โหลด Python เวอร์ชันล่าสุดสำหรับ macOS
3. รันไฟล์ติดตั้ง (.pkg)
4. หลังติดตั้งเสร็จ เปิด Terminal แล้วพิมพ์:
   ```
   python3 --version
   ```
   ถ้าขึ้นเวอร์ชันแสดงว่าติดตั้งสำเร็จ

**วิธีที่ 2: ใช้ Homebrew**
เปิด Terminal แล้วพิมพ์:
```bash
brew install python
```

### 2. ติดตั้ง Libraries ที่จำเป็น

**สำหรับ Windows:**
เปิด Command Prompt แล้วพิมพ์คำสั่งต่อไปนี้ทีละบรรทัด:

```bash
pip install pandas
pip install faker
pip install python-dateutil
```

**สำหรับ Mac:**
เปิด Terminal แล้วพิมพ์คำสั่งต่อไปนี้ทีละบรรทัด:

```bash
pip3 install pandas
pip3 install faker
pip3 install python-dateutil
```

## ขั้นตอนการใช้งาน

### ขั้นตอนที่ 1: เตรียมไฟล์ Input

ไฟล์ `SCK-insurance.csv` คือไฟล์ Input ที่ระบุเงื่อนไขการทดสอบ ประกอบด้วย Columns:
- `Timeline`: ระยะเวลาที่ต่ออายุล่วงหน้า (เช่น "90 - 30 วันล่วงหน้า")
- `Bundle`: ประเภทแพกเกจ (เช่น "SCK Family", "SCK Personal")
- `Family`: เงื่อนไขครอบครัว (ต้องตรงกับที่อยู่ใน `family-condition.csv`)

### ขั้นตอนที่ 2: เขียน Prompt ให้ AI

ต้องทำการเขียน Prompt ให้ AI เพื่อให้สร้าง Python Script โดยอ้างอิงจาก:

1. **Business Requirement Document.md** - อธิบายเงื่อนไขทางธุรกิจ
2. **family-condition.csv** - รายการเงื่อนไขครอบครัวทั้งหมด

**ตัวอย่าง Prompt:**
```
เขียน Python Script สำหรับสร้าง Mock Data สำหรับระบบประกันครอบครัว
โดยอ่านไฟล์ Input CSV และสร้าง Output CSV ตามเงื่อนไขใน Business Requirement Document.md
และ family-condition.csv

เงื่อนไขหลัก:
- วันที่ต่ออายุ (RENEWAL_DATE): 2026-09-12
- คำนวณอายุตามปฏิทินจริง
- ผู้ใหญ่อายุไม่เกิน 65 ปีบริบูรณ์
- เด็กอายุไม่เกิน 15 ปีบริบูรณ์
- ใช้ faker library สร้างชื่อไทยและข้อมูลสุ่ม
- บันทึกไฟล์ด้วย encoding utf-8-sig
```

### ขั้นตอนที่ 3: รัน Python Script

1. บันทึก Python Script ที่ AI สร้างให้ (เช่นชื่อ `generate-data.py`)
2. เปิด Command Prompt/Terminal ในโฟลเดอร์โปรเจ็ค
3. รัน Script ด้วยคำสั่ง:

   **สำหรับ Windows:**
   ```bash
   python generate-data.py
   ```

   **สำหรับ Mac:**
   ```bash
   python3 generate-data.py
   ```

4. Script จะสร้างไฟล์ Output CSV ให้

### ขั้นตอนที่ 4: ตรวจสอบผลลัพธ์

เปิดไฟล์ Output CSV ด้วย Excel แล้วตรวจสอบ:
- ข้อมูลผู้ถือกรมธรรม์ถูกต้อง
- ข้อมูลสมาชิกในครอบครัวตรงตามเงื่อนไข
- อายุคำนวณถูกต้อง
- วันที่อยู่ในรูปแบบไทย

## ข้อควรระวัง

### 1. การคำนวณอายุ

**หมายเหตุ:** Spec ระบุให้ใช้ `dateutil.relativedelta` สำหรับคำนวณอายุตามปฏิทินจริง เพื่อรองรับปีอธิกสุรทิน (Leap Year) และให้ความแม่นยำตามหลัก Business Logic

**สิ่งที่ต้องตรวจสอบ:**
- ตรวจสอบว่า AI ใช้ `dateutil.relativedelta` ตามที่ระบุใน spec
- ตรวจสอบว่าอายุคำนวณถูกต้องตามวันเกิดและวันที่อ้างอิง
- บาง AI Model อาจไม่ทำตาม spec ครบถ้วน ควรตรวจสอบ Output ด้วยตนเอง

### 2. ความสมจริงของข้อมูลครอบครัว

**ปัญหา:** ใน Spec เวอร์ชันปัจจุบันยังไม่ได้รองรับการสร้างข้อมูลที่มีความสมจริงเชิงลึก

**ตัวอย่างที่ควรปรับปรุง:**
- **อายุบุตร:** ถ้ามีบุตร 2 คน ควรห่างกันประมาณ 9 เดือนขึ้นไปเพื่อความสมจริง (เพราะไม่สามารถคลอดห่างกันน้อยกว่านั้น)
- **วันเกิดคู่สมรส:** ควรมีความเป็นไปได้ที่สมจริง (ไม่ห่างกันมากเกินไปหรือน้อยเกินไป)
- **ชื่อ-นามสกุล:** ควรมีความสัมพันธ์กันระหว่างสมาชิกในครอบครัว

**การปรับปรุง:**
เพิ่มเงื่อนไขใน Prompt ให้ AI คำนึงถึงความสมจริงเหล่านี้:
```
- ถ้ามีบุตร 2 คน ให้วันเกิดห่างกันอย่างน้อย 9 เดือน
- คู่สมรสควรมีอายุห่างกันไม่เกิน 20 ปี
- ให้บุตรใช้นามสกุลเดียวกับผู้ถือกรมธรรม์
```

### 4. การตรวจสอบข้อมูล

หลังจาก AI สร้าง Script แล้ว ควร:
1. รัน Script และตรวจสอบ Output อย่างน้อย 5-10 รายการ
2. เปรียบเทียบกับตัวอย่างใน `SCK_insurance_output_claude.csv`
3. ตรวจสอบ edge cases (กรณีพิเศษ) เช่น:
   - คนที่อายุเกินเกณฑ์
   - คนที่เสียชีวิต
   - กรณีที่ไม่มีคู่สมรส

## ตัวอย่างไฟล์ Output

ไฟล์ Output จะมี 6 Columns:

| Column | คำอธิบาย |
|--------|-----------|
| Timeline | ระยะเวลาที่ต่ออายุล่วงหน้า |
| Bundle | ประเภทแพกเกจ |
| Family | เงื่อนไขครอบครัว |
| ข้อมูลผู้ถือกรมธรรม์ | ชื่อ, เลขบัตรประชาชน, เบอร์โทร, อีเมล, วันเกิด, อายุ |
| ข้อมูลสมาชิกในกรมธรรม์ | รายละเอียดคู่สมรสและบุตร (ถ้ามี) |
| Status | วันที่ต่ออายุ, วันสิ้นสุดความคุ้มครอง, วันเริ่มสัญญา |
